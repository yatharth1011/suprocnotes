# SuprOC Notes

**SuprOC** = **Super Organic Chemistry**. JEE Advanced-level chemistry notes: organic chemistry in depth, plus key inorganic and physical topics. Mostly handwritten notebook pages, with typed theory sheets and PDFs, browsable in a simple web viewer.

## What's inside

**Organic**: Alkenes · Alkynes · Alkyl Halides & Haloform · Alcohols & Ethers · Carbonyl Compounds · Carboxylic Acids · Amines · Aromatic Compounds · Organometallics & Grignard's reagent · Practical Organic Chemistry (POC) · Biomolecules · Polymers

**Inorganic**: Metallurgy · Group 13 · Group 14 · Group 16 · d-block applications · f-block

**Physical**: Oxidation & Reduction

Each topic is a folder of notebook photos. Some also have a typed `*-THEORY.txt` summary and a PDF module (`amines_module.pdf`, `carbonyl_module.pdf`, `carbacids_module.pdf`, `polymers.pdf`).

## Viewing

Open `index.html` (the Notebook Viewer): pick a topic and flip through its pages. It's an installable PWA, so it works offline too.

After adding or renaming images, regenerate the viewer's index:

```bash
python3 gen.py
```
